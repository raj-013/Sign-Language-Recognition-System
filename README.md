Developing a system to translate Signs in Multiple Languages by training skeletal data using Machine Learning and OpenCV for faster and efficient recognition.
Implementing newer architectures like LSTM and Transformer to achieve up to 91% accuracy


To run the file you will have to manuall create the dataset, as that can't be uploaded here. We used a custom skeletal dataset which has the best accuracy in realtime amongst all the other publically available datasets. The code for the same is included.

The H5 files for resnet also needs to be manually created as it is too large to directly upload on git, code for the same can be found in the resnet pynb.
